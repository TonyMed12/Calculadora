# Calculadora

Calculadora web sencilla hecha con HTML, CSS y JavaScript puro, sin dependencias.

## Funcionalidades

- Operaciones básicas: suma, resta, multiplicación y división.
- Números decimales.
- Manejo de división entre cero (muestra "Error").
- Botón para limpiar la pantalla.

## Uso

No requiere instalación: abre `index.html` en el navegador.

## Estructura

- `index.html` estructura y botones
- `styles.css` estilos
- `script.js` lógica de la calculadora
